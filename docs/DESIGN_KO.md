# 중학교 2학년 과학 분자 시뮬레이터 설계

## 핵심 목표

학생이 1번부터 20번까지의 원소 입자를 생성하고, 태블릿에서 드래그해 서로 붙이거나 떼어 보면서 분자의 구성 원소, 원자 개수, 결합 구조를 탐구하는 3D WebGL 프로그램입니다.

## 기능 설계

### 1. 원소 생성

- 화면 하단 또는 좌측에 1번부터 20번까지 원소 버튼을 둡니다.
- 학생이 버튼을 누르면 해당 원소 입자가 실험 공간에 생성됩니다.
- 각 입자는 원소 기호와 색으로 구분합니다.
- 입자는 선택 후 삭제 버튼으로 지울 수 있습니다.

### 2. 드래그와 결합

- 태블릿 조작을 기준으로 터치 드래그를 지원합니다.
- 원자를 다른 원자 가까이 가져가면 결합 후보 지점이 표시됩니다.
- 손을 떼었을 때 충분히 가까우면 두 원자가 결합됩니다.
- 결합 후에는 현재 결합 구조가 이미 등록된 분자와 비슷한지 검사합니다.

### 3. 자동 정렬

- 등록된 분자의 원자 종류, 개수, 결합 구조가 맞으면 해당 분자의 3D 배치 정보에 맞춰 살짝 정렬합니다.
- 예: 물은 굽은 형태, 이산화탄소는 직선 형태, 메테인은 정사면체 느낌으로 배치할 수 있습니다.
- 학생이 만든 결과를 강제로 완전히 바꾸기보다, 수업용으로 보기 좋게 부드럽게 보정하는 방향이 좋습니다.

### 4. 분자 인식

분자 인식은 세 가지가 모두 맞아야 성공으로 처리합니다.

- 원자 종류
- 원자 개수
- 결합 구조

예를 들어 H2O는 H 2개, O 1개만으로 충분하지 않고, O가 두 H와 각각 결합된 구조여야 합니다.

### 5. 불안정 표시

등록된 분자와 일치하지 않는 구조는 "불안정한 구조"로 표시합니다.

학생의 자유 탐구를 막지 않기 위해 결합 자체는 허용하되, 수업적으로 의미 있는 분자인지 알려주는 방식입니다.

### 6. 분자 데이터 추가

선생님이 `Assets/Resources/molecules.json` 파일에 분자를 추가할 수 있습니다.

각 분자는 이름, 화학식, 원자 목록, 결합 목록, 3D 배치 좌표를 가집니다.

## WebGL 최적화 방향

- 원자 모델은 저폴리곤 구체를 사용합니다.
- 실시간 물리 시뮬레이션은 최소화하고, 드래그 중 위치 계산은 직접 처리합니다.
- 결합은 복잡한 3D 메시 대신 얇은 원기둥 또는 라인 렌더러로 표현합니다.
- 그림자와 후처리 효과는 끕니다.
- 모바일/태블릿에서 30 FPS 이상을 목표로 합니다.
- 한 화면에 생성 가능한 원자 수에 제한을 둡니다. 첫 버전은 40개 정도가 적당합니다.

## 다음 결정 사항

- 원소별 색상 규칙: 교과서 색상, 일반 분자모형 색상, 또는 직접 지정
- 수업 모드: 자유 만들기만 할지, "물을 만들어 보세요" 같은 미션 모드를 넣을지
- 삭제 방식: 선택 후 휴지통 버튼, 길게 누르기, 또는 화면 밖으로 드래그
